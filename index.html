About me

I build tools that keep an engineer in the loop with a language model rather than handing the work over to one. The pattern I keep returning to is the same: the model drafts, deterministic code audits the draft against a written standard, and a human makes the call. The interesting engineering is in that second step — the part that never calls a model at all.

My current project is Resume Forge, a desktop application that produces OPM-compliant federal resumes. Its most useful component is the compliance scanner, which never touches the API: it parses the draft, measures it against the published hiring rules, and flags every violation instantly and for free. The model writes; the rule engine keeps it honest.

This site is itself a working example. The panel under Forge runs on your own API key, stores nothing on any server, and tells you exactly where your text goes before it goes there.

What I do

  • AI-assisted document tooling

    Applications where a model drafts and deterministic code checks the result against a published standard before a person signs off on it.

  • Compliance and rule engines

    Parsers and auditors that measure a document against a written rule set. No model call, so the check is instant, repeatable, and free to run on every keystroke.

  • Secure API integration

    Bring-your-own-key integrations with real process isolation and OS-keychain storage, so a credential never sits somewhere it can leak from.

  • Accessible front-end work

    Keyboard-navigable, screen-reader-friendly interfaces that stay usable on a narrow phone viewport.
